# ADR 0001: Verbatim Gold 보존과 현재 채점 범위의 분리

- 상태: 재검토안 (`gold-v1-rc1`), 사용자 검토·실제 음성 파일럿 전
- 범위: 영어 OPIc STT 정답 전사 작성 규범. 채점 코드와 제품 모델 변경은 포함하지 않음
- 규범: [Gold Transcript 가이드](../ai/gold-transcript-guide.md)

## 문제와 코드 근거

기존 초안은 `referenceTranscript`에 완전한 단어를 쓰고 나머지를 주석에 남겼다.
그러나 이 채점용 단어열을 전체 verbatim Gold처럼 사용하면 문제가 생긴다.
`w-went`를 충실하게 전사한 모델이 `went`만 남긴 정답과 비교되어 삽입 오류를 받는다.
이는 조각 보존이 나쁘다는 증거가 아니라 정답 표현과 채점 방식의 불일치다.

현재 `transcription_metrics.py`는 영문·숫자·단어 내부 apostrophe만 단어로 추출한다.
사건 태그·단어 조각·한국어·미확정 구간을 이해하지 못한다. 필러와 인접 반복의
종류별 개수만 별도로 비교한다. `transcription_dataset.py`에는 주석·검수 상태 계약이 없다.

초안의 “모든 명확한 무발화 구간”도 작성 범위가 불명확했다. 짧은 자음 경계와
멈춤이 뒤섞일 수 있으며, 소수 둘째 자리 표기가 실제 측정 정확도를 보장하지 않는다.

## 이번 규범안의 결정

1. Gold 원본은 전체 기준 전사와 사건 기록을 포함한다. 미완성 조각·반복 횟수·
   불명확성은 채점기의 한계 때문에 버리지 않는다. 현재 `referenceTranscript`는
   Gold에서 검수하여 추출한 채점용 표현으로 한정한다.
2. 조각·단어 내부 중단·혼용 언어·복수 화자는 별도 수동 도전 자료로 보존한다.
   미확정 단어는 보류한다. 현재 주 WER에는 적격 샘플만 넣고 보류·분리 비율도 보고한다.
   제외 tag만으로 현재 CLI가 자동 분리한다고 설명하지 않는다.
3. 철자 기반 verbatim의 범위를 명시한다. 문법·단어 선택은 교정하지 않으며,
   악센트 자체를 임의 철자로 흉내 내지 않는다. 숫자·축약·약어·고유명사의 공통 표기를 정한다.
4. 내부 pause 후보의 잠정 주석 하한은 0.20초로 둔다. 이는 음성학·OPIc 판정 기준이
   아니며, 파일럿에서 경계 일치와 작업량을 확인하기 위한 운영 선택이다.
   단어 내부 중단, 앞뒤 여백, 경계 불확실성을 구별한다. 제품 임계값은 바꾸지 않는다.
   L2 pause 연구의 과제별 결과와 참고 범위는 가이드 7·12절에 명시한다.
   다른 과제에서 나온 결과를 OPIc 정답 기준의 검증 근거로 대신하지 않는다.
5. 두 독립 초안·불일치 판정·단어와 시간의 별도 검수 상태·버전 이력을 요구한다.
   실제 검증 전의 규범은 `gold-v1-rc1`로 표시하고, 외부 표준의 인증처럼 표현하지 않는다.

## 대안과 선택 비용

| 대안 | 판단과 비용 |
|---|---|
| 완전한 단어열만 Gold로 간주 | 구현은 쉽지만 조각 누락을 정답으로 만들고 풍부한 전사를 감점할 수 있어 선택하지 않음 |
| 모든 태그를 현재 `referenceTranscript`에 직접 삽입 | 자료는 한 곳에 있으나 현 채점기가 태그를 단어로 셈. 채점기 변경 전에는 사용할 수 없음 |
| CHAT 형식과 분석 도구를 전면 도입 | 풍부한 전사 체계가 있으나 교육·변환·도구 통합 비용이 큼. 이번 범위는 작성 규범 재정립이므로 개념을 참고하고 전체 도입은 보류 |
| 조각이 있는 샘플까지 단어열만 추출해 그대로 순위 비교 | 모델 출력에도 같은 추출이 필요하나 자동 인식·정렬 규칙이 없음. 현 단계의 공정한 순위 근거로 사용할 수 없음 |
| pause 하한 없이 모든 미세 간격 기록 | 범위와 작업량이 불명확하고 자음 경계 혼동 가능. 잠정 하한과 경계 보류 규칙을 택하되 파일럿 근거가 필요 |
| 한 명이 STT 출력을 수정해 Gold 작성 | 빠르지만 모델 편향과 검수자 독립성을 확인하기 어려움. 임시 자료와 독립 검수 Gold를 구별 |
| 즉시 주석 스키마·추출·시간·마스킹 채점 구현 | 필요할 수 있으나 실제 작성 사례와 규범의 재현성 검증이 먼저 필요. 별도 구현 범위 |

비공개 Gold와 manifest를 함께 관리하고 추출 결과를 수동 대조해야 한다.
어려운 자료를 주 WER에서 분리하면 주 점수의 대표성이 줄어든다. 따라서 분리 이유와
비율을 숨기지 않고 수동 도전 자료도 유지한다. 현재 주 WER만으로 전체 verbatim
품질이 우수한 모델이라고 결론 내릴 수 없다.

## 검증 상태와 재검토 조건

이번 변경은 문서와 현재 코드의 일관성을 검토한 규범안이다. 실제 OPIc Gold의
작성자 일치도, pause 하한의 타당성, 모델 전후 품질은 아직 측정하지 않았다.
새 규칙으로 더 좋은 점수를 얻었다거나 규범이 검증되었다고 주장하지 않는다.

파일럿에서 필러·조각·축약형·pause 경계의 반복적인 판단 충돌이 확인되면 후보판을
갱신한다. 정규화·주석·구간 제외 채점기를 도입할 때는 원문 보존과 양쪽에 동일한
규칙 적용을 검증한 뒤 평가 범위를 넓힌다. 변경 시 규칙·사전·Gold·데이터셋 버전을
함께 연결하고 모든 비교 대상에 같은 기준을 적용한다.
